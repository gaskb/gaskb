## 🚀 Featured Projects

### 🧠 Applied AI, Agents & Knowledge Systems
* **[EngramVault](https://github.com/gaskb/engramvault)** — Self-hosted, local-first AI Memory Vault, Epistemic Knowledge Graph (`FACT` / `CLAIM` / `DECISION`), Hybrid Search (`FTS5 BM25` + 384-dim semantic vectors + RRF), and native **Model Context Protocol (MCP 2.0)** server for AI agents (Antigravity, Claude Code, Cursor).  
  *Stack: Python, SQLite (WAL & FTS5), FastAPI, MCP 2.0, PWA*

* **[CozyTabs](https://github.com/gaskb/cozytabs)** — Personal Telegram bot using multimodal AI (Gemini audio + video reasoning) to analyze guitar video lessons (Reels, TikTok, Shorts) and generate structured study cards with ASCII tablatures and chords on Notion.  
  *Stack: Python, Google Gemini Multimodal, Notion API, Telegram Bot API*

### 🍏 Native macOS Utilities
* **[AiSentry](https://github.com/gaskb/aisentry)** — Native macOS menu bar utility for monitoring real-time consumption, quotas, and session limits across multiple AI providers (Claude, OpenAI, Google Gemini, Grok) with secure Apple Keychain storage.  
  *Stack: Swift, SwiftUI, macOS MenuBarExtra, Keychain Services*

* **[PingSentry](https://github.com/gaskb/pingsentry)** — Lightweight native macOS menu bar network monitor displaying real-time latency and packet loss using Wi-Fi-style indicator bars.  
  *Stack: Swift, SwiftUI, Network.framework*

### 🎛️ Audio DSP & Creative Code
* **[Livellatore](https://github.com/gaskb/livellatore)** — Dynamic voice auto-leveling VST3/AU audio plugin inspired by Sonic Anomaly TriLeveler, featuring target-level leveling, breath gate, and transparent brickwall limiting for podcasting and voice-overs.  
  *Stack: C++, JUCE, Audio DSP*

### 🔖 Self-Hosted & Lightweight Architecture
* **[Cozy-Bookmarks](https://github.com/gaskb/cozy-bookmarks)** — Minimalist self-hosted bookmark manager featuring clean Material 3 design, zero-build-step frontend, automated multi-provider AI tagging, strict anti-SSRF validation, and Android PWA support.  
  *Stack: FastAPI, HTMX, SQLite, Material 3, Docker*
